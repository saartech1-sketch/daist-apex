      World functions & variables

      World state

      • world.width, world.height — grid dimensions in cells.
      • world.tick — current simulation tick, starting at 0.
      • world.visibilityRange — maximum view distance; objects are visible only when their Euclidean distance is less than this range and no stone blocks the line of sight.
      • world.sheep — sheep position as {x, y}; x increases right and y increases down.
      • world.grass, world.water, world.stones, world.fences, world.wolves — arrays of visible objects, each with x and y. Stones block vision; stones and fences block movement.
      • world.board — full, unfiltered snapshot of the board state and object arrays. Use world.board.water (and the other object arrays) to inspect objects outside the sheep's visibility.
      • world.food, world.waterLevel, world.energy — current needs from 0 to 10. Food and water decrease each tick; grass restores food, water restores water, and resting restores energy. Eating or drinking takes 3 ticks during which the sheep cannot act.
      • world.lastAction — direction returned on the previous tick, or null.
      • world.lastFunction — name of the most recent action function that selected a direction, or null if none has yet.
      • world.lastMoveBlocked — whether the previous move was blocked by a stone, fence, or board edge.
      • world.DIRS — direction offsets: up, down, left, and right, each with dx and dy.
      • memory — a plain object that persists between ticks and clears on reset.

      Logging

      • log(...args) — writes debug output to the simulation log.

      Position and visibility

      • world.inBounds(x, y) — returns whether the coordinates are inside the grid.
      • world.isVisible(x, y) — returns whether the cell is within visibility range and has an unobstructed line of sight.

      Object checks

      • world.isStone(x, y), world.isFence(x, y) — check for visible stones or fences at a cell.
      • world.isGrass(x, y), world.isWater(x, y), world.isWolf(x, y) — check for visible grass, water, or wolves at a cell.
      • world.isBlocked(x, y) — checks whether a visible stone or fence blocks the cell.
      • world.isFree(x, y) — true for an in-bounds cell that is not visibly blocked by a stone or fence. It does not check for wolves, grass, or water.

      Computed variables

      • A variable is a function that takes no arguments and returns a value. Read current board and sheep state from world.
      • Every variable function is evaluated once each tick before action functions run. A returned value is stored in world.variables under that function's name.
      • For example, a variable named lowFood can be read directly inside action functions as world.variables.lowFood. Use its stored value; do not call it like a function.
      • Variables are recalculated at the beginning of each tick and overwrite their stored values. Existing values are not cleared first, but reset clears them. They do not update partway through a tick.
      • Variables run in the order shown in the Variables tab. A variable can read values already calculated earlier that tick from world.variables, but not itself or later variables; those would be previous-tick cached values.

      Action functions

      • An action function takes no arguments; read current state from world and computed values from world.variables.
      • Return exactly one direction: 'up', 'down', 'left', 'right', or 'stay'.
      • Action functions run in priority order after all variables have been calculated. Returning 'stay' skips to the next function; the first direction is performed. If every function returns 'stay', the sheep waits.
      • Movement into a stone, fence, or outside the grid is blocked. Wolves move each tick and kill the sheep on contact.

      Goal functions

      • A goal function takes no arguments and is evaluated after the action each tick, using the updated board and computed values in world.variables.
      • Return an integer from 0 to 3. Grade 0 continues the simulation; grades 1, 2, and 3 pass and stop it.
      • The goal result appears in the Goal tab. Any grade above 0 stops the simulation as a pass.
      • Use world.board to inspect all board objects, including those outside visibility.
